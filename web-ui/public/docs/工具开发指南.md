# 工具开发指南

工具把 Agent 的自然语言意图转换成可审计的业务动作。工具不是普通函数：它必须声明参数、风险、权限和失败语义。

## 工具定义

在 `python-engine/agent_runtime/tools/registry.py` 注册工具。一个推荐结构如下：

```python
from agent_runtime.tools.registry import ToolDefinition, tool_registry

async def query_order(arguments: dict, context: dict) -> dict:
    order_id = arguments["order_id"]
    order = await order_client.get(order_id)
    return {"order_id": order.id, "status": order.status, "amount": order.amount}

tool_registry.register(ToolDefinition(
    name="order.query",
    description="按订单号查询订单状态和金额",
    input_schema={
        "type": "object",
        "properties": {"order_id": {"type": "string"}},
        "required": ["order_id"],
    },
    handler=query_order,
    risk_level="low",
    requires_approval=False,
))
```

名称建议使用 `领域.动作`，例如 `invoice.read`、`refund.execute`、`ticket.create`。

## 参数校验

工具执行前必须按 JSON Schema 校验。不要让处理器自行猜测缺失字段。

```json
{
  "type": "object",
  "properties": {
    "order_id": { "type": "string", "minLength": 6 },
    "amount": { "type": "number", "minimum": 0.01 }
  },
  "required": ["order_id", "amount"],
  "additionalProperties": false
}
```

金额、账号、日期等关键字段应在服务端再次校验，不依赖模型生成正确格式。

## 风险与审批

| 风险 | 示例 | 默认处理 |
| --- | --- | --- |
| low | 查询、搜索、只读计算 | 直接执行 |
| medium | 创建草稿、发送内部通知 | 记录审计，可配置审批 |
| high | 付款、删除、外部发布 | 必须审批 |

高风险工具先创建审批任务，批准后使用原始参数继续执行。审批前不要产生不可逆副作用。

```python
if tool.requires_approval:
    approval = await approval_client.create(
        tool_name=tool.name,
        arguments=validated_arguments,
        session_id=context["session_id"],
    )
    return {"status": "waiting_for_approval", "approval_id": approval["id"]}
```

## 幂等与重试

写操作应接受幂等键：

```python
idempotency_key = f"{context['session_id']}:{context['tool_call_id']}"
result = await refund_client.execute(
    order_id=arguments["order_id"],
    amount=arguments["amount"],
    idempotency_key=idempotency_key,
)
```

网络超时不代表业务未成功。重试前先按幂等键查询结果，避免重复付款或重复通知。

## 错误返回

工具错误应结构化，区分可重试和不可重试：

```json
{
  "ok": false,
  "error": {
    "code": "ORDER_NOT_FOUND",
    "message": "订单不存在",
    "retryable": false
  }
}
```

不要把数据库异常、内部 URL 或堆栈直接返回模型。

## 测试清单

1. 正常参数返回稳定结构。
2. 缺少参数时拒绝执行。
3. 越权调用被权限层阻止。
4. 高风险工具必定产生审批任务。
5. 相同幂等键不会重复产生副作用。
6. 超时和供应商错误进入审计日志。
