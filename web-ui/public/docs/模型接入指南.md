# 模型接入指南

AgentHub 的 Python 执行面负责模型调用。建议优先使用 OpenAI 兼容协议，便于在不同供应商之间切换。

## 配置位置

运行时从项目根目录 `.env` 读取各供应商凭据：

```dotenv
DEEPSEEK_API_KEY=sk-replace-me
OPENAI_API_KEY=sk-replace-me
ANTHROPIC_API_KEY=sk-ant-replace-me
DASHSCOPE_API_KEY=sk-replace-me
MOONSHOT_API_KEY=sk-replace-me
ZHIPU_API_KEY=replace-me
```

只需配置实际使用的供应商。OpenAI 和 Anthropic 需要代理时，可分别设置 `OPENAI_BASE_URL`、`ANTHROPIC_BASE_URL`。

不同供应商常见地址：

| 供应商 | Base URL 示例 | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-v4-flash`、`deepseek-v4-pro` |
| 通义千问 | 阿里云兼容模式地址 | `qwen-plus` |
| 本地 vLLM | `http://127.0.0.1:8001/v1` | 本地模型名 |

## OpenAI 兼容请求

运行时最终发送的核心结构如下：

```python
payload = {
    "model": model_name,
    "messages": [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_message},
    ],
    "temperature": 0.3,
    "max_tokens": 2048,
    "stream": True,
}
```

供应商若不完全兼容，应在 `python-engine/agent_runtime/core/llm_client.py` 增加适配分支，不要在 Vue 页面拼供应商请求。

## 绑定模型到 Agent

在“Agent 管理”创建或编辑 Agent，模型字段必须与供应商实际模型 ID 一致。发布前完成以下检查：

1. API Key 有效且账户余额充足。
2. Base URL 可以从 Python 容器访问。
3. 模型支持所需上下文长度。
4. 若启用工具调用，模型支持 function/tool calling。
5. 超时大于供应商的首 Token 延迟。

## 用命令验证模型

先绕过 AgentHub，直接验证供应商：

```bash
curl "https://api.deepseek.com/chat/completions" \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role":"user","content":"只回复 OK"}],
    "stream": false
  }'
```

然后在工作台“对话实验室”验证 Java -> gRPC -> Python -> 模型的完整链路。

## 新增供应商适配

适配器应统一返回文本增量、工具调用和用量信息：

```python
class ProviderAdapter:
    async def stream(self, messages, tools=None):
        async for event in self.client.chat(messages=messages, tools=tools):
            if event.type == "text":
                yield {"type": "text", "content": event.text}
            elif event.type == "tool_call":
                yield {"type": "tool_call", "name": event.name, "arguments": event.arguments}
```

不要把供应商响应对象直接传播到 Java 或前端，否则切换供应商会破坏上层协议。

## 安全建议

- 密钥只进入 Python 运行时，不返回浏览器。
- 生产环境限制模型出口域名。
- 日志中屏蔽 Authorization 头和完整提示词。
- 为高成本模型设置预算和并发限制。
- 使用独立的开发、测试、生产密钥。
