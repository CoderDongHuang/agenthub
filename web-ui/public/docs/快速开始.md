# 快速开始

本指南用于在本地启动 AgentHub 的完整链路：PostgreSQL、Redis、Java 管理面、Python 执行面和 Vue 工作台。

## 环境要求

| 组件 | 建议版本 | 用途 |
| --- | --- | --- |
| Docker Desktop | 4.x | PostgreSQL 与 Redis |
| JDK | 21 | Java 管理面 |
| Maven | 3.9+ | Java 构建 |
| Python | 3.11.9 | Agent 执行引擎 |
| Node.js | 22.19.0 | Vue 工作台 |

## 1. 配置环境变量

复制项目根目录的 `.env.example`，按实际供应商填写模型密钥。没有模型密钥时，管理功能仍可使用，但 Agent 对话无法生成真实回复。

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_NAME=agenthub
DB_USER=agenthub
DB_PASSWORD=replace-me
REDIS_URL=redis://:replace-me@localhost:6380/0
DEEPSEEK_API_KEY=sk-replace-me
JWT_SECRET=replace-with-a-random-32-byte-value
AGENTHUB_INTERNAL_TOKEN=replace-with-a-random-secret-of-at-least-32-characters
```

不要把真实密钥提交到 Git。生产环境应通过容器 Secret 或部署平台的加密变量注入。

## 2. 启动基础设施

在项目根目录执行：

```powershell
docker compose up -d postgres redis
docker compose ps
```

`postgres` 和 `redis` 都显示 `healthy` 后再启动应用。Java 启动时 Flyway 会自动执行 `java-console/src/main/resources/db/migration` 下的迁移。

## 3. 启动 Java 管理面

```powershell
cd java-console
mvn spring-boot:run
```

验证服务：

```powershell
Invoke-RestMethod http://localhost:8080/api/health
```

## 4. 启动 Python 执行面

新开终端：

```powershell
cd python-engine
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

验证运行时：

```powershell
Invoke-RestMethod http://localhost:8000/health
```

## 5. 启动工作台

再开一个终端：

```powershell
cd web-ui
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。若端口占用，Vite 会自动选择下一个端口，以终端输出为准。

## 6. 登录并验证

开发环境默认账号：

```text
用户名：admin
密码：admin123
```

登录后按以下顺序验证：

1. 打开“Agent 管理”，确认能读取 Agent 列表。
2. 打开“知识库”，上传一个 TXT、Markdown、PDF 或 DOCX 文件。
3. 等待状态变为“已索引”，查看实际切片数量。
4. 打开“流程编排”，保存流程并运行，确认产生执行记录。
5. 打开“用量分析”，真实对话完成后会出现 Token 和成本记录。

## 常用停止命令

应用终端使用 `Ctrl+C` 停止。基础设施使用：

```powershell
docker compose stop
```

需要连同容器删除时使用 `docker compose down`。不要加 `-v`，除非明确希望删除数据库卷。
