## 基础配置

真实值只写根目录 `.env` 或生产密钥库。

| 配置 | 当前状态 | 生产要求 |
| --- | --- | --- |
| `DB_*` | 已配置 | 使用独立账号、TLS、备份和最小权限。 |
| `REDIS_URL` | 已配置 | 使用认证、TLS、持久化/高可用和专用实例。 |
| `JWT_SECRET` | 已配置 | 至少 32 字符，不与其他根密钥复用。 |
| `AGENTHUB_INTERNAL_TOKEN` | 已配置 | Java/Python 一致，仅内部网络传输。 |
| `AGENTHUB_KMS_MASTER_KEY` | 已配置且独立 | 轮换前先迁移既有密文。 |
| `AGENTHUB_ECOSYSTEM_SIGNING_KEY` | 已配置且独立 | 仅用于制品签名。 |
| `AGENTHUB_CORS_ORIGINS` | 本机已配置 | 上线后改为明确 HTTPS 域名，禁止通配符/localhost。 |
| `AGENTHUB_SECURE_COOKIE` | 本机 HTTP 为 `false` | HTTPS 生产必须为 `true`。 |

production profile 会拒绝短值、占位值、互相复用的四类根密钥、非 Secure Cookie、通配符和 localhost CORS。
