## 必需基础配置

所有真实值只填写根目录 `.env`，不要写入本文、`.env.example` 或提交到 Git。

| 变量 | 当前状态 | 如何获得或填写 |
| --- | --- | --- |
| `DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASSWORD` | 已配置 | 对应 Docker Compose 的 PostgreSQL 服务；本机默认端口 5432。 |
| `REDIS_URL` | 已配置 | 对应本机 Redis，当前端口 6380；密码保留在本地 `.env`。 |
| `JWT_SECRET` | 已配置 | 使用密码生成器生成至少 32 字节随机值。 |
| `AGENTHUB_KMS_MASTER_KEY` | 可选，当前回退 `JWT_SECRET` | 本地开发可省略；长期保存托管密钥前应生成独立的至少 32 字节随机值。更换该值前必须先完成密钥迁移，否则旧密文无法解密。 |
| `AGENTHUB_ECOSYSTEM_SIGNING_KEY` | 可选，当前回退 KMS 主密钥或 `JWT_SECRET` | 私有制品签名专用密钥，建议使用密码生成器生成独立的至少 32 字符随机值。只写入根目录 `.env`，已签名制品仍在使用时不要直接更换。 |
| `AGENTHUB_INTERNAL_TOKEN` | 已配置 | 使用密码生成器生成至少 32 字符随机值，Java 与 Python 必须相同。 |
| `AGENTHUB_CORS_ORIGINS` | 已配置 | 本地使用 `localhost/127.0.0.1:5173`；不部署公网时无需真实域名。 |
| `AGENTHUB_SECURE_COOKIE` | 已配置为 `false` | 本地 HTTP 必须为 `false`；只有切换 HTTPS 后才设为 `true`。 |

## 多模态语义供应商

统一选择阿里云百炼 DashScope 的国内免费额度方案：`qwen-vl-plus` 完成图片 OCR/视觉理解，`qwen3.5-omni-flash` 完成音频和视频音轨转写，一个 `DASHSCOPE_API_KEY` 覆盖三类能力。Java 适配器已接入并通过请求格式、结构化响应、无 Key 降级、错误脱敏和视频音轨抽取契约测试；只有供应商真实返回 JSON 时任务才标记为 `completed`，调用错误标记为 `failed/provider_error`。

| 变量 | 填写位置 | 当前状态 |
| --- | --- | --- |
| `DASHSCOPE_API_KEY` | 仅根目录 `.env` | 在阿里云百炼控制台创建 API Key 后填写；不得提交 Git。 |
| `DASHSCOPE_VISION_MODEL` | 根目录 `.env` 或保留示例默认值 | 默认 `qwen-vl-plus`，用于 OCR 和视觉理解。 |
| `DASHSCOPE_AUDIO_MODEL` | 根目录 `.env` 或保留示例默认值 | 默认 `qwen3.5-omni-flash`，用于音频和视频音轨转写。 |
| `DASHSCOPE_API_BASE_URL` | 通常不填写 | 默认国内兼容地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`。 |
| `FFMPEG_PATH` | 根目录 `.env`；未填写时使用 PATH 或本机常见路径回退 | 视频语义抽取前用于本地提取音轨；Windows 可填写 `D:/PythonCode/ffmpeg/bin/ffmpeg.exe`。 |

获取路径：登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，进入 API Key 管理创建 Key，并在模型服务/模型广场确认 `qwen-vl-plus` 与 `qwen3.5-omni-flash` 对当前地域和账号可用。免费额度、计费规则和数据使用条款以百炼控制台当前说明为准，敏感生产数据应先确认合规策略。语义上传采用内联媒体，单文件限制 18 MB；更大的音频或图片应先压缩/切分，视频会先由本地 FFmpeg 抽取音轨。

## 已知外部限制

- 企业微信回调唯一未闭环项是企业主体域名，不是本机代码或凭据问题。
- 飞书与钉钉公网回调依赖当前 cpolar 隧道持续运行。
- 未配置的模型供应商不能执行对应 Agent，这是预期的快速失败行为。
- DashScope 多模态适配器已完成契约测试；未填写百炼 Key 前，真实 OCR/视觉/转写调用按设计返回 `needs_provider`。
- Kubernetes 主/备地域配置已完成静态渲染和镜像构建，本机未部署真实集群；跨地域 PostgreSQL/Redis 一致性需要外部基础设施。
- 本项目只在本机运行并开源到 GitHub，未配置公网生产域名、HTTPS Cookie 或云端数据库。
